# Evaluation-methodology review: hn-rerank ML

Scope: `scripts/eval_ranker_variants.py`, `scripts/simulate_interleaving.py`, `scripts/interleave_report.py`, `pipeline/interleave.py`, docs/evaluations. No code run; no DB in this copy.

## 1. Top findings, ranked by value/effort

**1. Make the day-forward shown-pool eval the gate, not judged-only replay. — evaluation gap.**
Evidence: judged-only `heldout-feedback` is the vehicle that selected #2/#4 (`INTERLEAVING.md`), yet the harness itself warns it has "higher positive density: do not compare" (`eval_ranker_variants.py:3037`, `--candidate-pool` help `:2394`). `_metrics` (`:1884`) scores recovery of known votes; shown-but-unvoted cards are unjudged and invisible, so a model that would surface duds live is never penalised. The `impressions` pool exists (`:2643`, `_with_skipped` `:1411`) but only with `--holdout-after`, adds 25–50 extras per block, and `auc_up_vs_all` (`:1927`) treats any shown-unvoted card as not-upvote, conflating skip/never-opened/never-seen. Effect on aims: current metrics over-reward familiarity and under-test discovery, currency, and dud-rate — exactly the sameness failure. Effort: S (machinery exists; cf. diversity-20261012/PLAN.md Phase 0 and discovery-20261012/PLAN.md Phase 0, which already score "stories first shown that day, outcome = up after first showing"). Validation: rerun shortlist on `--candidate-pool impressions --holdout-after <fresh-cut>` plus the daily first-shown protocol; primary metrics P@8/down@8/up-rate, not AUC. Confidence: high.

**2. Current-content embeddings leak future text into every fold. — defect (acknowledged, unquantified).**
Evidence: eval reuses current stored `text_content`/`top_comments`/`article_body` for train and test; own `interpretation` admits "current stored content" (`:3037`); Discover/Diversity plans note "HN points and comments read at snapshot time (leak)". Comments fetched days after the vote (CH prewarm, tap hydration) and article bodies enriched later are visible to the train and test rows of early folds. TF-IDF/joined-logistic (word features) plausibly gain most. Effect: inflates all absolute AUC/NDCG, biases word-vs-no-word comparisons, says nothing about sameness either way. Effort: M (title-only sensitivity is S: `_tfidf_text` title mode `:1490`, `TEXT_LENGTH_BUCKETS`; full time-travel content is L). Validation: re-run #2 vs #4 vs production on title-only + frozen-text ablation via `eval_ranker_variants.py --dump-scores` + `compare_eval_scores.py`; require the word-model margin to survive before crediting it. Confidence: high that leak exists, medium on its size.

**3. Trial attribution/statistics ignore clustering, exposure, and position. — defect.**
Evidence: credit = last Recommended impression before vote + 1 s slack (`interleave_report.py:103-137`); per-deck sign test + two-proportion z assume independent credits (`simulate_interleaving.py:152-229`, `interleave_report.py:141-180`). Multiple credits in one deck are correlated (same 8–12 cards, same session); the far card truncates the draft so arm counts differ by one (`pipeline/interleave.py` docstring); skipped-card exposure is unmodelled; undone votes vanish (survivorship); one unblinded user. The Oct-12 addendum added Newcombe/Wilson CIs and frozen-snapshot rules (`INTERLEAVING.md` addendum) but the CI is still unclustered. Effect: p-values/CIs too tight; a "win" could be a few good decks, with no diversity guardrail in the decision rule. Effort: S (analysis-only, post-trial). Validation: on the frozen endpoint snapshot, add deck-clustered SEs (block bootstrap over versions, already used in ablation `fresh.json`), exposure-weighted rates, and per-position credit balance; report novel-up (`sim<0.60`) and down-rate alongside up-rate. Confidence: high.

**4. No power at the endpoint; selection and confirmation reuse the same labels. — evaluation gap.**
Evidence: replay promised ~70%/#2 at 28 d with ~486 credits/arm, but live runs ~13.5/d → ~125/arm, i.e. the replay's 7-day row ("low power"; `INTERLEAVING.md` power table + Oct-12 61-credit note). #2/#4 were selected on the same 12 blocks the replay replays ("exploratory, not confirmation"). Confirmation reserve exists (latest 20% timestamp groups excluded unless `--confirmation`, `:2601-2697`) and `--holdout-after/--holdout-blocks` (`:2236`) plus `--leak-check` shuffles (`:3130`) exist, but the ship decision rests on the live test that is now underpowered. Ablation README explicitly notes "no practical equivalence margin was predeclared." Effect: endpoint likely "no significant difference" — correctly read as *no detectable large difference*, not equivalence; shipping the simpler model on that basis would be a judgement call, not a statistical conclusion. Effort: S (pre-register now). Validation: freeze endpoint DB per addendum commands; report up-rate difference + 95% Newcombe interval; predeclare an equivalence margin and a harm (down-rate) bar before looking; use `--confirmation` + fresh `--holdout-after` blocks as the offline confirmation. Confidence: high.

**5. Main metric suite does not measure the four aims. — evaluation gap.**
Evidence: `_metrics` has `ndcg_at_k`, `auc_up_vs_rest/down/all`, `known_upvote_fraction_at_12` (`:1893-2060`); novelty is only `discovery_upvotes_at_12` via a per-fold median split (`_novel_candidate_ids` `:1860` — relative, not the live 0.60 rule) and `non_hn_upvotes_at_12`. Diversity (pairwise 1−cosine, topic entropy, novel-caught, down-rate) lives only in the offline diversity/discover Phase-0 scripts (`diversity-20261012/PLAN.md`, `~/revote/sameness-metrics.py`, FINDINGS "Sameness"), not in `eval_ranker_variants.py` reports. Effect: AUC/NDCG gains can coexist with a same-y feed; no metric would catch it. Effort: M (port Phase-0 metrics into the eval report). Validation: for each `--dump-scores` fold, compute top-k up-rate, down-rate, novel-up rate (sim<0.60 to pre-cutoff ups), non-HN ups, pairwise diversity, topic entropy; gate ranker changes on no-loss of novel-ups + diversity alongside up-rate (diversity gate already written: +0.05 diversity, ≤2 pt up-rate loss). Confidence: medium-high.

**6. Cold-start / small-profile performance is proxied, not measured. — evaluation gap.**
Evidence: `--train-recent N` truncates heavy-user history (`:2252`, INTERLEAVING.md short-history table) — "profile 151's recent votes stand in for a new user's first votes," which the doc admits "supports, but does not establish" anything about new users. New-profile first feed is an explicit Goal (STATUS.md) and parked. Effect: challengers tuned on thousands of votes may underperform where it matters most for growth/showcase; sameness risk differs by history length. Effort: M. Validation: leave-one-profile-out / short-history curve on small profiles + cold-deck depth metric (cf. `COLD_DECK_MARGIN` fix); keep as secondary gate after proposal 1. Confidence: medium. Uncertain: whether small profiles have enough votes for a stable read.
