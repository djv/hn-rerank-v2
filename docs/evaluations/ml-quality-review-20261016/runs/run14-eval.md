# Evaluation-methodology review: hn-rerank ML ranker

## 1. Top findings / proposals (ranked)

### P1. Make the impressions pool + served-deck replay the primary offline gate
**Category:** evaluation gap (defect-adjacent). **Evidence:** `scripts/eval_ranker_variants.py:2390-2398` (`candidate-pool current|heldout-feedback|impressions`); `_make_fold` retained-set logic; `diversity-20261012/PLAN.md` Phase 0 and `discovery-20261012/PLAN.md` Phase 0 both state "pool holds only stories already shown, shown-but-unvoted counts as not liked"; `model-ablation-20261007/INTERLEAVING.md` power replay "every candidate is judged… optimistic".
Judged-only replay measures recovery of already-shown votes, not live ranking over the full pool. It rewards models that re-find shown items and cannot penalize reaching deeper — directly against discovery/stay-current. The harness already has the fix: `_impression_pools`, `SkippedPool`, `--candidate-pool impressions`, and served-deck scoring via `_recommended`/`serve_window`/`_metrics:recommended_1w`.
**Aims:** saves time stays measured; discovery/current/coverage become measurable instead of assumed; sameness: pairs naturally with diversity/novelty slices below. **Effort:** M (reruns only, no prod change). **Validation:** rerun shortlist #2/#4 and any challenger on `heldout-feedback` *and* `impressions` with `--holdout-after/--holdout-blocks`; require agreement on up-rate, `discovery_upvotes_at_12`, `non_hn_upvotes_at_12`. **Confidence:** high.

### P2. Treat snapshot content/scores as known leakage; add an as-of-vote sensitivity
**Category:** concrete defect (partial). **Evidence:** `_load_production_candidates` loads current `Story` rows; `story_embedding_text` uses current `text_content`; discovery Phase 0 limits admit "HN points and comments read at snapshot time (leak)"; `_scores_window_gravity:765-775` comment "points are the snapshot's". Counter-evidence (fine): TF-IDF vocab is train-only (`_tfidf_features`), joined word-keep is train-only (`pipeline/joined_classifier.py:fit`), scaler is train-only (`_fit_scale`), similarity uses LOOCV self-exclusion (`pipeline/ranking.py:_loocv_knn_features`). So vocabulary/scaler/similarity are clean; *content freshness* is not: test-item embeddings/scores include post-vote comments, edits, and late points.
**Aims:** inflates absolute AUC/NDCG for all arms; may favor text-heavy/edited stories; sameness effect uncertain. **Effort:** M (timestamped text/scores ideal; cheap proxy now). **Validation:** report title-only/titledom TF-IDF (`_scores_tfidf text=title`), comment-stripped embeddings, and age-gated slices alongside full-text numbers; use `TEXT_LENGTH_BUCKETS` and `raw_short/long` lanes; run `--leak-check` shuffle. **Confidence:** medium-high on existence, medium on magnitude.

### P3. Adopt a four-aim metric suite with preregistered gates; stop ranking by AUC/NDCG@12 alone
**Category:** evaluation gap. **Evidence:** `_metrics:1876+` already computes `auc_up_vs_rest/down/all`, `ndcg_at_k`, `up_recall_at_k`, `known_upvote/down/neutral_fraction_at_12`, `non_hn_upvotes_at_12`, `discovery_upvotes_at_12` (novel = max-sim-to-ups < 0.60), `not_returned_eligible_positives`, `brier_up`; but study tables/report headlines select AUC, NDCG@12, upvotes-per-48/144 (e.g. `FEATURE-REMOVALS.md`, `README.md` ablation table). Diversity work shows why: "no re-rank rule passed the gate" and Far 1 "just missed" on a fixed gate (`FINDINGS.md` Diversity/Discover Phase 0; `diversity-20261012/PLAN.md` gate: diversity +0.05, up-rate within −2pp, novel not fewer).
**Proposal:** primary = exposure-aware top-k worth-reading rate + down-risk; co-primaries = novel up-votes (`<0.60`) and non-HN up-votes at 12/40; guardrails = mean pairwise `1−cosine`, topic entropy, `not_returned_eligible_positives`/served shortfall, `brier_up`. Preregister an equivalence margin — "no significant difference ≠ tie" (`stopping-rule-review-20261013/ASSESSMENT.md`). Report block-bootstrap + story-bootstrap + sign-flip together via `scripts/compare_eval_scores.py` (as `FEATURE-REMOVALS.md` does), never one alone.
**Aims:** directly maps to save-time/discovery/current/calmer-habit; sameness becomes a gate, not commentary. **Effort:** S (mostly reporting discipline). **Validation:** re-render #2 vs #4 twelve-block comparison with the full suite and CIs; a model must not pass on AUC while losing novel/non-HN. **Confidence:** high.

### P4. Fix the live-credit denominator and dependence before any post-trial claim
**Category:** concrete defect (partially fixed). **Evidence:** `scripts/interleave_report.py:credit_votes` last-impression-wins with `IMPRESSION_SLACK_SECONDS=1.0`, keys `(version,window,story_id)`; `summarize/compare` pooled two-proportion z + deck sign test; `simulate_interleaving.py:compare` same pooled test. Verified limits in `stopping-rule-review-20261013/ASSESSMENT.md`: pooled votes ignore deck/session clustering and adaptive refit-after-every-vote; denominator is credited votes, not exposed cards; `feedback` is mutable so `--until` alone is not reproducible. Already fixed and kept: Bonferroni over 2, Newcombe/Wilson descriptive CI, one-sided down-harm test, half-open `[T0,endpoint)`, pre-T0 deck rejection, calibration-interval exclusion (`INTERLEAVING.md` reporting addendum; `STATUS.md` result). Remaining: 11-served cut breaks round balance (unbiased in expectation, noisier per deck; `diversity-20261012/FAR-CARD-REVIEW.md:L3`, `pipeline/interleave.py:62-86` docstring stale); far votes in headline `credited`/`decks_with_credit` (FAR-CARD-REVIEW L2); 1s slack is not a clock-skew guarantee.
**Aims:** prevents a same-y or dud-heavy winner from passing on a biased denominator; sameness needs an explicit exposure + diversity guardrail in stage 2. **Effort:** S/M (analysis-only; no restart before 2026-11-05). **Validation:** freeze endpoint snapshot (`endpoint.db` backup recipe in `INTERLEAVING.md`), rerun `interleave_report.py` with recorded exclusions; add deck-clustered SE and exposure-normalized secondary as descriptive (not a retroactive rule change). Live power is low (~13.5 credits/day vs replay's 50/day; ~125/arm ≈ replay's 7-day row) — prespecify "inconclusive" as a valid outcome. **Confidence:** high.

### P5. Lock the temporal protocol: expanding-window + URL-group + fresh-vote confirm + short-history curve
**Category:** untried improvement (protocol). **Evidence:** `_temporal_splits`, `_holdout_splits` (expanding window), `_recent_training`, `--confirmation` (reserved latest 20%), `--train-recent`, `--holdout-after/--holdout-blocks`; `--split stratified` is retired by hard error (good); `_make_fold` keeps first-held-out-vote-per-URL-group and dedups candidates by `_url_group`. Re-vote contamination is handled ad hoc: 29 calibration rows excluded via `--exclude-updated-between` (`interleave_report.py`, `STATUS.md` next step).
**Proposal:** default every model decision on: temporal expanding blocks with URL-group isolation; a `--confirmation`/fresh-holdout rerun on votes newer than any tuning; `--train-recent 100/200/400` cold-start curve (already used once in `INTERLEAVING.md` short-history table — keep it mandatory for any "works for new profiles" claim); frozen-DB + embedding-snapshot hashes (`frozen_database`, `_snapshot_context`); `--leak-check` shuffle. Exclude calibration/re-vote intervals by default, not by memory.
**Aims:** protects stay-current (fresh votes) and first-feed claims; small-n honesty for other profiles. **Effort:** M. **Validation:** any post-trial challenger must pass heldout + confirmation + short-history before interleaving. **Confidence:** medium (process fix; exact N thresholds open).

## 2. Checked: fine or already tried

- LOOCV self-exclusion for kNN similarity, scaler fit on train only, TF-IDF/joined vocab (`min_df`/`count>=2`) on train only — clean; do not relitigate.
- Stratified shuffle retired (`--split stratified` errors) — correct; keep temporal.
- URL-group isolation (first vote per article; candidate dedup preferring held-out ID) — already in `_make_fold`; fine.
- Trial corrections (Bonferroni-2, Newcombe/Wilson, one-sided down test, half-open window, pre-T0 + calibration exclusions, far-arm exclusion from tests) — verified; remaining issues are P4 secondaries.
- Rejected directions, do not re-propose without new evidence: stacked GBM/ordinal/pair/LR (`_scores_stack`), TF-IDF char/title sweeps (`_scores_tfidf`), metadata-scale middle (x0.5/x0.25 falls between #2/#4), remove-word/content ablations, recency half-life and dwell-weighted fits, Teach/active-learning Phase 0 (tiny gain, parked), Muse pairwise feature mining (`RANKING-REASSESSMENT-20261009.md` verdict NONE), linear `svm_c` plateau (gone; live `config.toml` is `svm_c=4.0` + blend + side embeddings, contradicting `ARCHITECTURE.md`'s "pins 0.1" — read `config.toml`, not the doc).
- Raw embeddings must stay unscaled; `StandardScaler` touches metadata from `emb_dim:` onward — respected in `_fit_scale`/`_svm_personalization_features`.
